# cash

A shell written from scratch in C. work in progress

## Build

```
make
./Cash/cash
```

## What it has

- builtins: `dp`, `sft`, `drm`, `rmv`, `lnp`, `fref`, `show`, `undo`
- runs external commands
- pipes: `|`
- redirection: `<`, `>`, `>>`

## What it doesnt have

variables, scripting, job control, history and config file
do NOT use as daily shell
